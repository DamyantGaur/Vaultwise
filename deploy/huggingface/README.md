# Vaultwise (cloud demo)

Ask questions about company documents and get answers that cite the exact clause, or an honest
"not in your document". This Space is a **demo** loaded with three fictional sample documents.
The AI model (Llama 3.2 3B via Ollama) runs inside this container; no third-party AI service is used.

For real confidential documents, use the local version, which never leaves your computer.
This Space is deployed automatically by the project's GitHub Actions CI/CD pipeline.
